Introduction

Vortyx Pulse gives you a single model, vortyx-1, for text-based chat and reasoning. Every request goes to the same base URL and endpoint.

Base URL
https://vortyx-pulse-backend.onrender.com/v1

All requests and responses are JSON over HTTPS.

Audio and video are not available yet. The API and dashboard currently support text only — those modalities will be added once the model supports them.

Authentication

Every request must include your API key in the Authorization header. Keys are created and revoked from your dashboard.

1 Authorization: Bearer vp_live_••••••••••••••••
Keep keys server-side. Never expose a live key in client-side code. Use a backend relay if you need to call Vortyx Pulse from a browser or mobile app.

Quickstart

1. Create a key

Sign up, then generate your first API key from the API Keys tab in your dashboard. Free accounts can create up to 5 keys.

2. Send a request

1 curl https://vortyx-pulse-backend.onrender.com/v1/chat \ 2 -H "Authorization: Bearer vp_live_••••••••" \ 3 -H "Content-Type: application/json" \ 4 -d '{"input": "Say hello"}'

3. Read the response

1 { 2 "id": "resp_8f2ac1", 3 "model": "vortyx-1", 4 "output": "Hello! How can I help?", 5 "usage": { "input_tokens": 4, "output_tokens": 6 } 6 }

Streaming

Not available yet — every response is currently returned in full once generation finishes, rather than streamed incrementally.

API keys

Keys are created from the dashboard and shown once at creation, then masked. Use the eye icon next to a key to reveal it again at any time, or the revoke button to permanently disable it.

  • Free plan: up to 5 active keys
  • Any paid plan: unlimited keys
  • Revoked keys stop working immediately and cannot be restored
