Introduction

Vortyx Pulse gives you a single model, vortyx-1, that reasons across text, audio, and video through one API. Instead of separate providers for chat, speech, and vision, every request goes to the same base URL — you just change the modality.

Base URL
https://api.vortyxpulse.com/v1

All requests and responses are JSON over HTTPS, except audio/video binary uploads, which use multipart form data.

Authentication

Every request must include your API key in the Authorization header. Keys are created and revoked from your dashboard.

1 Authorization: Bearer vp_live_••••••••••••••••
Keep keys server-side. Never expose a live key in client-side code. Use a backend relay if you need to call Vortyx Pulse from a browser or mobile app.

Quickstart

1. Create a key

Sign up, then generate your first API key from the API Keys tab in your dashboard. Free accounts can create up to 5 keys.

2. Send a request

1 curl https://api.vortyxpulse.com/v1/chat \ 2 -H "Authorization: Bearer vp_live_••••••••" \ 3 -H "Content-Type: application/json" \ 4 -d '{"model": "vortyx-1", "input": "Say hello"}'

3. Read the response

1 { 2 "id": "resp_8f2ac1", 3 "model": "vortyx-1", 4 "output": "Hello! How can I help?", 5 "usage": { "input_tokens": 4, "output_tokens": 6 } 6 }

Chat / text

POST/v1/chat

Send a text prompt and get a reasoning response back. Supports multi-turn conversation via the messages array.

ParamTypeDescription
modelstringAlways "vortyx-1" required
inputstringPrompt text required
modalitystring"text" (default), "audio", or "video"
streambooleanStream the response as it's generated

Audio

POST/v1/audio

Send speech directly into the model — no separate transcription step. Vortyx Pulse listens, reasons, and can respond in natural spoken audio.

1 from vortyx import Client 2 3 client = Client(api_key="vp_live_••••••••") 4 5 with open("call.wav", "rb") as f: 6 response = client.audio.create(model="vortyx-1", audio=f, voice="natural")

Video

POST/v1/video

Upload a video file or stream frames — the model reasons across frames rather than sampling a single still image, so it can answer questions about motion, sequence, and timing.

1 response = client.video.create( 2 model="vortyx-1", 3 video=open("clip.mp4", "rb"), 4 input="What happens at the 10 second mark?" 5 )

Streaming

Set "stream": true on any endpoint to receive output incrementally as server-sent events, rather than waiting for the full response.

1 for chunk in response: 2 print(chunk.delta, end="")

API keys

Keys are created from the dashboard and shown once at creation, then masked. Use the eye icon next to a key to reveal it again at any time, or the revoke button to permanently disable it.

  • Free plan: up to 5 active keys
  • Any paid plan: unlimited keys
  • Revoked keys stop working immediately and cannot be restored
